# ESP32 Simple Web Server (esp32_sensing)

This example demonstrates how you can use a Bluetooth Low Energy (BLE) game controller to operate an LED and a servo motor. We will configure the left joystick on the controller to operate the servo and use the buttons to operate the LED.

This example demonstrates how you can host a simple web server from the ESP32. This lets you manually build out similar functionality to what you saw in the ESP Home example.

## What you will need -

- ESP-32 Development Board
- LED (Optional - you can use the onboard LED if you wish)
- 220 Ohm Resistor (Optional)
- Breadboard (Optional)

## Circuit Diagram

No Circuit is needed here, you only need your ESP 32 to be connected to your computer.
